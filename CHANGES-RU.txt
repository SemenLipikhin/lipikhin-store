Проверка и обновление LIPIKHIN

Последняя правка:
- Вытянутые равнозначные кнопки без стрелок, мягкое скругление 16px, обычный регистр и системный шрифт.
- Состояния hover, active и focus-visible; движение отключено при reduced-motion.
- Два исходных фото веером через CSS. На ширине до 760px композиция под текстом с меньшим наклоном.
- Изменены только HomePage.jsx и HomePage.css относительно предыдущей версии.
- Применены рекомендации emil-design-eng, apple-design, mobile-native из https://github.com/emilkowalski/skills.
- Браузер предпросмотра не подключился к локальному серверу; визуальная проверка и проверка на настоящем телефоне не завершены.

Изменено:
- Удалены три блока 01–03 и их CSS.
- Главный экран без внешней рамки, подложки, скругления и тени.
- Нижние карточки коллекций полностью удалены. Выбор «Мужское / Женское» перенесён под описание в главный блок, в две равнозначные кнопки.
- Старые кнопки «Смотреть коллекции» и «Женская линия» заменены новым выбором коллекции.
- Исправлены базовые пути внутренних ссылок для GitHub Pages.
- Исправлен конфликт padding у главной и нижней строки футера.
- Мобильные кнопки меню и аккаунта увеличены до 44px.

Проверено: npm run build, npm run lint — успешно.
Ограничение: обновлённая версия не прошла визуальную проверку в браузере.

Осталось:
1. App отображает только главную: страниц каталога, корзины, избранного, аккаунта и помощи нет. Исправление префикса ссылок само по себе эти страницы не создаёт; переходы пока будут давать 404.
2. Поиск — только input без обработки запросов.
3. Подписка отключена с честной подписью «скоро появится».
4. Внешние Google Fonts требуют сети; резервные шрифты предусмотрены.

Как применить:
Скопируйте src из архива в существующий проект с заменой файлов.
Не удаляйте свою папку .git или .github.
В терминале: npm run dev
Для публикации после проверки: git add .; git commit -m "Refine homepage layout"; git push
