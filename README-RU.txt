LIPIKHIN — учебный интернет-каталог одежды

Стек: React 19, React Router 7, Vite 8. Сайт работает без backend, базы данных и оплаты.

Запуск в VS Code:
1. Откройте папку проекта в VS Code.
2. В терминале проекта выполните npm ci.
3. Запустите npm run dev.
4. Откройте адрес, который покажет Vite (обычно http://localhost:5173/lipikhin-store/).

Проверки: npm run build, npm run lint, npm test.

Что работает:
- Главная страница, мужская и женская коллекции, общий каталог, поиск с подсказками по первым буквам названия или типа вещи и распродажа.
- На десктопе каталог показывает пять товаров в ряд. На телефоне сетка адаптируется.
- На страницах товаров есть галерея, выбор размера, закрытые по умолчанию описание и уход.
- Корзина хранит размер и количество, пересчитывает сумму и остаётся после перезагрузки.
- Избранное сохраняет выбранный размер и остаётся после перезагрузки.
- В «Личном кабинете» можно создать, изменить и удалить локальный профиль (имя и почта). Пароль не запрашивается; настоящей регистрации, входа и истории заказов нет. Профиль сохраняется только в localStorage этого браузера.
- Корзина и избранное сохраняются только в localStorage данного браузера. После очистки данных браузера они исчезнут; синхронизации между устройствами нет.

Распродажа в учебном макете:
- Куртка-блузон: 12 900 → 9 900 ₽.
- Джемпер фактурной вязки: 11 900 → 8 900 ₽.
Это демонстрационные цены и скидки, а не подтверждённые коммерческие предложения. Итог корзины считается по текущей цене из src/data/products.js, в том числе для ранее добавленных товаров.

Ограничения:
- Заказы, оплата, доставка, подписка, авторизация и хранение данных на сервере не подключены. Сайт не сообщает об успешной покупке и не собирает данные для заказа.
- Перед реальными продажами нужны проверенные цены, ассортимент, размеры, остатки, составы, условия доставки и возврата, контакты и серверная обработка заказов.
- Цены и размеры женских товаров указаны для демонстрации и требуют проверки перед реальными продажами. Для мужской джинсовой рубашки предметный кадр product-only-illustration.jpg создан генерацией по исходным фото и должен быть заменён настоящим снимком перед продажами.

Структура проекта:
- src/data/products.js — модели, цены, фото, размеры и скидки (oldPrice больше price).
- src/data/navigation.js — разделы каталога и пункты меню.
- src/pages — страницы магазина.
- src/components — шапка, футер и карточки товаров.
- src/store — корзина и избранное, сохранение в localStorage.
- src/utils/commerce.js — работа с корзиной, ценами и сохранёнными данными.
- src/utils/search.js — совпадения поиска и подсказки.
- src/utils/profile.js — проверка локального профиля.
- public/images — фотографии товаров.
- tests — проверки логики магазина.
